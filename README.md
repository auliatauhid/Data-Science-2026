## 🚀 Cara Menjalankan

### Opsi 1 — Google Colab

**Google Colab direkomendasikan** untuk menjalankan notebook tanpa perlu melakukan konfigurasi environment secara manual.

1. Buka notebook yang ingin dijalankan.
2. Klik badge **Open in Colab** apabila tersedia.
3. Pilih **Runtime → Run all**.
4. Jalankan seluruh cell pada notebook.

### Opsi 2 — Menjalankan Secara Lokal

Pastikan **Python 3.x** dan **Jupyter Notebook** telah terpasang.

#### 1. Clone Repository

```bash
git clone https://github.com/auliatauhid/Data-Science-2026.git
```

#### 2. Masuk ke Direktori Repository

```bash
cd Data-Science-2026
```

#### 3. Install Dependencies

```bash
pip install pandas numpy matplotlib seaborn scikit-learn scipy requests gdown
```

#### 4. Jalankan Jupyter Notebook

```bash
jupyter notebook
```

Setelah itu, buka notebook yang ingin dijalankan melalui browser.

# 🔄 Data Science Lifecycle

Secara keseluruhan, 13 pertemuan ini membentuk sebuah siklus pembelajaran Data Science yang terintegrasi:

```text
📥 Mendapatkan Data
        ↓
🧹 Membersihkan Data
        ↓
🔍 Mengeksplorasi Data
        ↓
📊 Memvisualisasikan Data
        ↓
⚙️ Rekayasa Fitur
        ↓
🤖 Memodelkan Data
        ↓
📏 Mengevaluasi Model
        ↓
🎯 Mengoptimalkan Model
        ↓
🚀 Deploy
```

Dengan demikian, proses Data Science tidak berhenti pada pembuatan model, tetapi mencakup keseluruhan proses dari **data acquisition hingga deployment**.
